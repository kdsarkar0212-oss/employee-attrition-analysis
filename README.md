# Employee Attrition Analysis & Prediction

## Project Overview
An end-to-end HR analytics project that analyzes employee attrition patterns and predicts employee turnover using Python, SQL, Machine Learning, and Power BI.

## Objectives
- Analyze employee attrition trends.
- Identify key factors associated with employee turnover.
- Compare machine learning classification models.
- Build an interactive Power BI dashboard.
- Present data-driven HR insights.

## Tools & Technologies
- Python (Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn)
- SQL (SQLite)
- Machine Learning (Logistic Regression, Decision Tree, Random Forest)
- Power BI
- Google Colab

## Project Workflow
1. Data cleaning and preprocessing
2. Exploratory Data Analysis (EDA)
3. SQL-based business analysis
4. Machine Learning model development
5. Model evaluation and feature importance
6. Interactive Power BI dashboard

## Dashboard Pages
1. Executive Overview
2. Attrition Drivers
3. Predictive Analytics

## Repository Files
- `Employee_Attrition_Analysis_Complete.ipynb` – Complete analysis and machine learning notebook
- `employee_attrition_project_outputs.zip` – Processed datasets, model results, predictions, and supporting outputs
- `README.md` – Project documentation

## Dataset
IBM HR Analytics Employee Attrition sample dataset.

## Important Note
This project uses sample HR data for educational and analytical purposes. Model predictions should not be used as automated employment decisions. Findings indicate associations, not proven causes.
